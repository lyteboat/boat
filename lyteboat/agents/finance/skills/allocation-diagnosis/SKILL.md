# 配置诊断

1. 调用 `allocation_diagnosis` 一次。用户在对话里说过的投资期限、每月支出、已授权账户以外的资产，填进对应的参数；没说过的不填，不要猜。
2. 用户撤回之前说过的某一笔外部资产时，对那一笔填 `remove: true`。
3. 按【回答要点】组织回答：先用一句话给结论，再解释偏离最大的两项。卡片标记按要点放在对应的位置，单独一行。
4. 【回答要点】里给了要问用户的问题时，回答最后只问这一个问题。
5. 工具返回 `state=runway` 时，说明资产还不到 3 个月支出，建议先攒应急金，不讨论配置。
6. 用户追问诊断结果里已有的数字时，直接从最近一次的【事实】里答；用户说「重新诊断」或补充了新情况时重新调用。
